## What got built tonight

1. **The hub runs.** `drh-hub` (Rust, axum) serves the web UI on http://127.0.0.1:2828.
   Built `web/` (vite) and `hub/` (cargo) from source; both compile clean.
2. **Apps wired to their real homes.** `apps/Research-Acquisition/yt-transcript-downloader` is a
   junction to `D:\GitHub\Research-Acquisition\yt-transcript-downloader` (old copy kept as
   `yt-transcript-downloader.hub-copy`). `apps/Axiom-Navigator` is a junction to
   `D:\React\Axiom-Navigator` — the finished-canon surface, launchable from the hub
   (`axiom.navigator` serves it on :8774, `axiom.build` rebuilds it).
3. **Story import (Writer).** Story JSON dropped in `data/writer/stories/` shows in the Story
   tab: spans highlighted in the doc, ◀ ▶ variant cycler with word diffs, keep/use buttons,
   needed-vs-optional checklist chips. Choices saved per doc in `data/writer/story-state/`.
   Sample: `sample-hooks`.
4. **Rewrite-by-selection (Writer build step 2).** Right-click a selection → five "Rewrite: …"
   modes (shorter, plainer, as the Skeptic, the unforgotten sentence, custom). Runs through
   OpenRouter with `OPENROUTER_API_KEY` (server-side only). Results land as blue pending
   rewrites; accept/reject in the Review tab. Prompts: `prompts/W_rewrite.json` + `W_rewrite/`.
   **Why it never worked before:** upstream's AI path calls the hosted, billed Author's Voice
   service, which doesn't exist in this copy — the buttons were real, the brain wasn't.
5. **Craft opening (dual story import).** Story tab → "Craft opening": one call takes the
   selection/first paragraph + hub research, returns three graded openings (research-grounded /
   story / youtube-transcript) plus grades for the current text, all against the live checklist.
   Prompts: `prompts/W_craft.json`.
6. **Model note.** DeepSeek was the first choice but this OpenRouter account's provider
   allowlist blocks its hosts. Default is `openai/gpt-4o-mini` (sub-cent per call). To use
   DeepSeek: allow streamlake/deepinfra at https://openrouter.ai/settings/privacy, then flip the
   model in `prompts/W_rewrite.json`, `prompts/W_craft.json` and the plugin's model config.
7. **The three questions** sit on top of the story checklist (`say`, `believe`, `original`).
8. **Raw research dumps work.** Drop loose `.md` or folders of markdown into
   `data/deep_research/` — no run.json needed; they become research cards and craft context.
9. **Truth nodes.** Snippet library in `data/writer/nodes.json`: right-click → "Save as truth
   node", or paste into the Story tab's Truth nodes section; search + insert-at-cursor.
10. **Standalone.** `apps/openwriter/START_OPENWRITER.bat` runs the Writer without the hub.
