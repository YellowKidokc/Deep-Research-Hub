Score only the opening paragraph(s) of the document as a Kait Willett-style intro: clear, authoritative, research-backed, and built to make the reader need the next paragraph.

Use this rubric for the `overall.rubric`:
- Hook & Engagement: does the first sentence create an open question?
- Authority & Evidence: are claims attached to a source, sample size, or specific number?
- Clarity & Pace: is every word doing work, with no throat-clearing?
- Kait Loop Fit: does it use at least one of these moves — concrete number, comment + engagement, study + sample, contradiction, dead predictor, before/after stat, pricing reframe, narrow hedge?
- Voice: does it sound like one person telling the truth, not a summary?

In `sections`, create one section for the opening only. Raise 1–3 issues, quoting exact words from the opening. For each issue, name which Kait loop would fix it (if any) and ask a next-step question.

In `reply`, give one sentence: the single highest-value loop to add or change.
