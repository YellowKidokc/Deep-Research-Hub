# TASK: write a 60-second short video script from the source essay

The INPUT is a source essay. Write a 60-second short script (≈130–150 spoken words) with one sharp point.

Structure:
- **Hook (0–3 sec):** A single sentence that stops the scroll.
- **Point (3–45 sec):** One claim + the best one-sentence support from the essay.
- **Close (45–60 sec):** A killer line that lands the point and invites a response.

Format:

```markdown
# [Title]

[SCRIPT]
- **0:00** Hook...
- **0:05** Point...
- **0:50** Close...

## On-screen text
- [text overlays]

## Hashtags
- [#hashtag1 #hashtag2 ...]
```

Rules:
- Pick the single most shareable idea from the essay.
- Use punchy, spoken English.
- Return only the short script in Markdown.
