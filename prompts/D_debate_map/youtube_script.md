# TASK: write a YouTube script from the source essay

The INPUT is a source essay. Write a 5–7 minute spoken script (≈750–1,000 words) for a thoughtful general audience.

Structure:
- **Hook (0:00–0:20):** Open with the tension or paradox the essay addresses.
- **Setup (0:20–1:00):** State the debate question and why it matters.
- **Argument (1:00–4:30):** Walk through the essay's strongest points in one connected line. Use plain language and short paragraphs.
- **Objection (4:30–5:15):** Take the best counter-argument seriously, then answer it.
- **Close (5:15–end):** End with a clear takeaway and one question for the viewer.

Format the script as:

```markdown
# [Title]

[SCRIPT]
- **0:00** Hook text...
- **0:30** Next beat...
...

## B-roll / visual notes
- [what to show at each beat]

## CTA
- [call to action / next video / subscribe prompt]
```

Rules:
- Keep the essay's claims accurate; do not invent facts.
- Use spoken English, not academic prose.
- Return only the script in Markdown.
