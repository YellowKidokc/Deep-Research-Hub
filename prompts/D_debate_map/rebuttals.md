# TASK: write objection/response pairs from the source essay

The INPUT is a source essay. Generate the strongest objections a skeptic would raise against its argument, and concise responses drawn from the essay.

Output a Markdown file with this exact structure:

## Objection/Response pairs

**Objection 1:** [state the objection in the skeptic's voice, strongly]

**Response:** [answer the objection using only claims and evidence in the essay]

---

**Objection 2:** ...

**Response:** ...

Rules:
- Write 3–5 pairs.
- Objections must be genuinely strong, not straw men.
- Responses must stay grounded in the essay; do not invent new evidence.
- Return only the pairs. No intro, no conclusion.
