#  The Power Set
The power set will be a major component of our connection between sets and the laws of thought. While we will carefully avoid getting lost in too much algebra, we'll find it convenient to give them their own symbol and algebra if only to simplify the text itself. We will therefore call the power set ![$\\Pi$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img10.png) and refer to the power set of a set ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png) as ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png). We will also need to think about the power set of a power set and so on:   

![\\begin{displaymath}\\Pi^2\(S\) = \\Pi\(\\Pi\(S\)\) \\end{displaymath}](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img13.png)
  
  

![\\begin{displaymath}\\Pi^3\(S\) = \\Pi\\left\(\\Pi\\left\(\\Pi\(S\)\\right\)\\right\)\\end{displaymath}](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img14.png)
  
  

![\\begin{displaymath}...\\end{displaymath}](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img15.png)
  

As it is our plan to consider thought only in the context of the _real Universe_ we need a very concrete set to play with to figure out what ![$\\Pi$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img10.png) is and how it works. Consider, therefore, the set consisting of four cards pulled out of an ordinary deck of playing cards. To make differentiating easy, we'll pull out the four aces and consider each card to be labelled by its _suit_. 
Our toy set is thus:

where the first entry is the _empty set_ about which we will have much to say later. In general there are ![$2^C$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img35.png) such permutative subsets, where ![$C$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img36.png) is the number of elements in the original set ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png), called the _cardinality_ of the set. 
There are two general kinds of things we can ``do'' algebraically with ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png) in terms of thought, reason, and language. One is that we can identify particular sets from ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png) by means of a suitable predicate expression. For example, I can ``create a set that has one card that is a black suit and is not a spade'' to uniquely define the set  ![$\\left\\{
\\framebox{$\\clubsuit$}\\right\\}$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img37.png). 
There will often be many ways to create a predicate that specifies a single subset from the power set, but there is one way that _always_ will exist. We can always specify the subset by explicitly specifying the list of its members[3.13](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/footnode.html#foot3795). We will call this method ``identification'' as it appears to be somehow related to the law of identity. Note that we use identification of the elements of the original set ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png), plus the processes of permutation and union to generate ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png). It seems difficult to imagine - literally - working with a set whose members cannot be identified independent of predicates used to describe them. 
The second kind of thing we can do is to _identify_ (in precisely this sense or via predicates) particular _sets_ of subsets drawn from the ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png). If we specify (for example) ``the set of all sets in ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png) that contain a heart'' we end up with:

...clubsuit$}, \\framebox{$\\diamondsuit$}, \\framebox{$\\heartsuit$}\\right\\}, \\right.$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img38.png)  |   |  
| --- | --- | --- | --- |  
|   |   | ![$\\displaystyle \\quad\\quad\\quad \\left. \\left\\{\\framebox{$\\clubsuit$}, \\framebox{$...

Note that there is no way to collapse or reduce this to a member of the original power set. Each of these sets is an object in its own right that satisfies the criterion for selection. 
This set of subsets (drawn from ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png)) is itself a subset from a set of subsets of the subsets of the original set ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png)[3.14](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/footnode.html#foot3397). Clearly this set is ![$\\Pi^2\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img40.png). There seems to be no reason we cannot similarly recursively generate ![$\\Pi^n\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img41.png) for any finite ![$n$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img42.png) by iterating the process of making ![$\\Pi^{n+1}\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img43.png) out of the sets generating by permuting the members of ![$\\Pi^n\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img41.png) taken from 0 to the cardinality of times[3.15](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/footnode.html#foot3912) . 
Of course, this process scales fairly agressively. We cannot actually _draw_ even ![$\\Pi^2\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img40.png) because the number of elements in it is  ![$2^{2^4} = 2^{16} = 65536$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img45.png), and the number of elements in the ![$\\Pi^3\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img46.png) is  ![$2^{2^{2^4}} = 2^{65536}$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img47.png) and so on. However, if the cardinality of the original set ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png) is finite, so is the cardinality of the ![$\\Pi^n\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img41.png) for any finite ![$n$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img42.png). It's just large. 
This may seem like a rather lot of complexity - in only the third level power set we already have considerably more objects than atoms in the physical Universe, for example, and it was _only_ four cards! However, nothing less will do, as the answer to _any set theoretic question we can ask_ must lie therein. Fortunately for us all, in the physical Universe a great deal of this complexity can be compressed by the human mind into _structure_. 
We have already performed such a simplification - imagine if we specified ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png) in terms of the very large set of molecules that make up the cards, of the even larger set of atoms that make up the molecules, of the larger still set (call it, say, ![$S_e$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img48.png)) of of elementary particles (electrons and quarks and the various field quanta) that make up the atoms and their nuclei. The first level power set ![$\\Pi\(S_e\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img49.png) would contain many absurd (non-physical) subsets, but it would also include subsets that contained just three quarks and an electron, which on a good day could take on a new name: a ``hydrogen atom''. Indeed, follow the process of forming power sets forward, we will discover therein sets of sets of elementary particles that aggregate into other atoms, sets of sets of sets that aggregate into molecules, and so on up to cards. 
So each of our cards is _actually_ internally organized into structures that can be treated as independently identifiable subsets, themselves aggregated into independently identifiable subsets, all part of a whole hierarchy of ![$\\Pi^n\(S_e\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img50.png). The card is just one out of a _very large number_ of such subsets, with all sorts of internal symmetries. The count of permutations, and permutations of permutations, etc. scales up extremely rapidly, which is why statistical mechanics works as well as it does in physics. There is no infinity there, but there are plenty of finities that (as I like to tell my students) are really _good friends_ with infinity, their children play together, every now and then they all get together at infinity's house and drink a few beers. 
We are therefore fortunate indeed that the human brain more or less automatically makes this sort of hierarchical decomposition when confronted with permutative power set-theoretic information that even at the first or second levels causes our internal number-registers to beep and return ``overflow''. And this is still, recall, _just four cards_. Imagine dealing with a _deck_ of cards, or a Universe with _many_ decks of cards that are one tiny part of one tiny planet in one small solar system in a single galaxy. Yet when I refer to each of these things, your mind _effortlessly_ erases all the detail and replaces it with a _hierarchy_ drawn from power set upon power set all the way down to whatever the _real, existential_ microscopic elementary set of objects are that make up the Universe (where we might have to include all of the points in space and time some way in our set descriptions. 
There are a number of consequences of this hierarchical decomposition. One to keep in mind is that when we reason about anything _real_ (as opposed to mathematics, which might be real, might not - lots of controversy there and I don't want to get into it) we are forced to do so at the level of one of these ![$\\Pi^n\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img41.png), and maybe a few recursions on either side of it. We _cannot_ extend our reasoning down to the indefinitely microscopic or up to the indefinitely macroscopic. It is absurd to try to understand the rules of poker in terms of the properties and motion of the elementary particles of the Universe _even though every particle in the game_ obeys rules defined at that level at _all times_. Nor do we compute the effect of folding a hand in the poker game on the motion of the Milky Way galaxy as it meanders around in the gravitational field of all the other galaxies in the Universe. More _is_ different, and so is _less_. 
For this and many other excellent reasons that we'll go into, our _actual_ reasoning process about the _actual_ Universe is almost immediately forced to be _probabilistic_. This suggests that when we get around to axioms and all that, one of the _first_ things we should work out is the mathematics of _induction_ as the process of building the hierarchies is necessarily inductive as _otherwise there is no reason to favor any particular decomposition over any other_. We must _find_ a reason, or give up on ``reason'' altogether. 
For the moment, though, let's _ignore_ all this appalling complexity and go _back_ to just the some given finite set ![$S$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img11.png) and maybe ![$\\Pi\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img12.png) and ![$\\Pi^2\(S\)$](https://webhome.phy.duke.edu/~rgb/Philosophy/axioms/axioms/img40.png), just to see what insight we can gain from this formulation into the laws of thought.
