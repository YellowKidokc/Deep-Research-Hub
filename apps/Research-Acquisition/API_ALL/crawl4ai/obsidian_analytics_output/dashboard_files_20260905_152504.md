## META: WHY DEFINITIONS COME FIRST

> "Everything starts with a definition. If it doesn't have a definition, it's probably not true."

The classical error is to begin with axioms before fixing vocabulary. But an axiom is a *proposition* — and a proposition requires *terms*. If the terms are undefined, the axiom is empty. This rebuild corrects that: **DEFINITION → DECLARATION → AXIOM → BOUNDARY → DERIVATION → BRIDGE → MODEL → EMPIRICAL → THEOLOGICAL → INTERPRETATION**.

Each entry carries:
- **Classification** (per the taxonomy)
- **Plain Language** (simplest grammatical sentence)
- **Mathematical Notation** (if reality-bound)
- **Truth Status** (is this stipulative, admitted, derived, or tested?)
- **Opposite / False Version** (what worldview denies this?)
- **God Perspective** (what does this look like from a theological frame?)
- **Science Perspective** (what does this look like from a scientific frame?)
- **Theories on the False** (named worldviews, beliefs, or theories that hold the negation)
