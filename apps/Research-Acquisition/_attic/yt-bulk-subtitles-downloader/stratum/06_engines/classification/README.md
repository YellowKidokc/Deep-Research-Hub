# Stratum Classification Canon

This folder is the single home for Stratum's classification standards.

It currently contains:

- `NABLA_CHI_UNIVERSAL_CLASSIFICATION_STANDARD_v1.0.md`
- `NABLA_CHI_CLASSIFICATION_QUICK_REFERENCE.md`
- `TRUTH_STACK_ARCHITECTURE_NOTE.md`
- `prompts/01_NABLA_SEMANTIC_FILE_NAMING_SYSTEM_v5.1.md`
- `prompts/02_LOSSLESS_CONTEXT_COMPRESSION_PROTOCOL_v2.0.md`
- `prompts/03_NABLA_ADDRESS_DECODER.md`
- `prompts/04_MASTER_EQUATION_TRUTH_COHERENCE_DIAGNOSTIC_PROMPT.md`

Use this folder as the canonical source for:

- artifact naming and address rules
- semantic vector rules
- truth stack and claim-mode rules
- claim-type gates
- coherence and risk review posture
- defensibility and repair language

The popup actions that surface this material are:

- `classification_canon`
- `classification_quick_map`

The design goal is simple:

1. keep the full standard in one stable place
2. keep the runtime popup actions small and usable
3. avoid prompt drift by treating the canon as source material, not as a scattered note
