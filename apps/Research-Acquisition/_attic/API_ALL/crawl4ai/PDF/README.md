## 🚀 How to Use

### Step 1: Add HTML Files
1. Copy your HTML files to the `inbox/` folder
2. You can add as many as you want

### Step 2: Run Conversion
1. Double-click `Convert_HTML_to_PDF.bat`
2. The script will:
   - Count HTML files in inbox
   - Install dependencies if needed (first time only)
   - Convert each HTML to PDF
   - Save PDFs to `outbox/`
   - Move processed HTML to `processed/`

### Step 3: Get Your PDFs
1. Find your PDFs in the `outbox/` folder
2. Processed HTML files are in `processed/` (for backup)

## 📝 Tips

**For Best Results:**
1. Use well-formatted HTML files
2. Ensure all CSS is embedded or linked correctly
3. Images should use absolute paths or be embedded
4. Test with one file first

**If Text is Too Small:**
- Edit the HTML file before conversion
- Add CSS: `body { font-size: 14px; }` or larger
- Or modify the Python script to inject custom CSS

**Multiple Conversions:**
- You can run the batch file multiple times
- It only processes files in `inbox/`
- Already processed files won't be re-converted

## 🛠️ Troubleshooting

**"No HTML files found"**
- Make sure files are in `inbox/` folder
- Check file extensions (.html or .htm)

**"Playwright not found"**
- Run the batch file - it will auto-install
- Or manually: `pip install playwright`
- Then: `python -m playwright install chromium`

**PDF looks wrong**
- Check if HTML displays correctly in browser first
- Verify all resources (CSS, images) are accessible
- Try disabling single-page mode (edit Python script)
