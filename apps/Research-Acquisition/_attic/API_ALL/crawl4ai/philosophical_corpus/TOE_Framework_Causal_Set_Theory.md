The **causal sets** program is an approach to [quantum gravity](https://en.wikipedia.org/wiki/Quantum_gravity "Quantum gravity"). Its founding principles are that [spacetime](https://en.wikipedia.org/wiki/Spacetime "Spacetime") is fundamentally discrete (a collection of discrete spacetime points, called the elements of the causal set) and that spacetime events are related by a [partial order](https://en.wikipedia.org/wiki/Partial_order "Partial order"). This partial order has the physical meaning of the [causality relations](https://en.wikipedia.org/wiki/Causality_relation "Causality relation") between spacetime events. 
## History
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=1 "Edit section: History")]
Causality has always had a fundamental role in physics. Early attempts to use causality as a starting point were made by [Hermann Weyl](https://en.wikipedia.org/wiki/Hermann_Weyl "Hermann Weyl") and [Hendrik Lorentz](https://en.wikipedia.org/wiki/Hendrik_Lorentz "Hendrik Lorentz").[[1]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-1) [Alfred Robb](https://en.wikipedia.org/wiki/Alfred_Robb "Alfred Robb") in two books in 1914 and 1936 suggested an axiomatic framework where the causal precedence played a critical role.[[2]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Surya-2) The first explicit proposal of quantizing the causal structure of spacetime is attributed by Sumati Surya[[2]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Surya-2) to E. H. Kronheimer and [Roger Penrose](https://en.wikipedia.org/wiki/Roger_Penrose "Roger Penrose"),[[3]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-3) who invented causal spaces in order to "admit structures which can be very different from a manifold _"_. Causal spaces are defined axiomatically, by considering not only causal precedence, but also chronological precedence. 
The program of causal sets is based on a theorem[[4]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Malament-4) by [David Malament](https://en.wikipedia.org/wiki/David_Malament "David Malament"), extending former results by [Christopher Zeeman](https://en.wikipedia.org/wiki/Christopher_Zeeman "Christopher Zeeman"),[[5]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-5) and by [Stephen Hawking](https://en.wikipedia.org/wiki/Stephen_Hawking "Stephen Hawking"), A. R. King and P. J. McCarthy.[[6]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-6)[[2]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Surya-2) Malament's theorem states that if there is a [bijective](https://en.wikipedia.org/wiki/Bijection "Bijection") map between two [past and future distinguishing](https://en.wikipedia.org/wiki/Past_and_future_distinguishing "Past and future distinguishing") space times that preserves their [causal structure](https://en.wikipedia.org/wiki/Causal_structure "Causal structure") then the map is a [conformal isomorphism](https://en.wikipedia.org/wiki/Conformal_map "Conformal map"). The conformal factor that is left undetermined is related to the volume of regions in the spacetime. This volume factor can be recovered by specifying a volume element for each space time point. The volume of a space time region could then be found by counting the number of points in that region. 
Causal sets was initiated by [Rafael Sorkin](https://en.wikipedia.org/wiki/Rafael_Sorkin "Rafael Sorkin") who continues to be the main proponent of the program. He has coined the slogan "Order + Number = Geometry" to characterize the above argument. The program provides a theory in which space time is fundamentally discrete while retaining local [Lorentz invariance](https://en.wikipedia.org/wiki/Lorentz_invariance "Lorentz invariance"). 
## Definition
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=2 "Edit section: Definition")]
A causal set (or causet) is a set  C {\displaystyle C} ![{\\displaystyle C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/4fc55753007cd3c18576f7933f6f089196732029) with a [partial order](https://en.wikipedia.org/wiki/Partial_order "Partial order") [relation](https://en.wikipedia.org/wiki/Binary_relation "Binary relation") ⪯ {\displaystyle \preceq } ![{\\displaystyle \\preceq }](https://wikimedia.org/api/rest_v1/media/math/render/svg/63dfe475e1377b3b4e936a3aa8fb1d7177dcdbc3) that is 
  * [Reflexive](https://en.wikipedia.org/wiki/Reflexive_relation "Reflexive relation"): For all  x ∈ C {\displaystyle x\in C} ![{\\displaystyle x\\in C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/f7fc788379bff7289bdf694ffd68ee690e999eb7), we have  x ⪯ x {\displaystyle x\preceq x} ![{\\displaystyle x\\preceq x}](https://wikimedia.org/api/rest_v1/media/math/render/svg/6d52b7f462d1950c7b52e6d09fc140e4738d85bd).

  * [Locally finite](https://en.wikipedia.org/wiki/Locally_finite_poset "Locally finite poset"): For all  x , z ∈ C {\displaystyle x,z\in C} ![{\\displaystyle x,z\\in C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/7afd86bebb09ff7be5b8b23ce0cf58b39f9e90be), we have  { y ∈ C | x ⪯ y ⪯ z } {\displaystyle \\{y\in C|x\preceq y\preceq z\\}} ![{\\displaystyle \\{y\\in C|x\\preceq y\\preceq z\\}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/6ce0f8dd558a36c415c69935b0bc720ccd4f88f1) is a finite set.


We'll write  x ≺ y {\displaystyle x\prec y} ![{\\displaystyle x\\prec y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/61de07b95a935ac198f35c2b0eb8aa0babdb2fb1) if  x ⪯ y {\displaystyle x\preceq y} ![{\\displaystyle x\\preceq y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c51521f83e947000789960c7804a542a2f609942) and  x ≠ y {\displaystyle x\neq y} ![{\\displaystyle x\\neq y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/f51b711ca7f932963cdb268b0817dc72d6258733). 
The set  C {\displaystyle C} ![{\\displaystyle C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/4fc55753007cd3c18576f7933f6f089196732029) represents the set of [spacetime events](https://en.wikipedia.org/wiki/Event_\(relativity\) "Event \(relativity\)") and the order relation  ⪯ {\displaystyle \preceq } ![{\\displaystyle \\preceq }](https://wikimedia.org/api/rest_v1/media/math/render/svg/63dfe475e1377b3b4e936a3aa8fb1d7177dcdbc3) represents the causal relationship between events (see [causal structure](https://en.wikipedia.org/wiki/Causal_structure "Causal structure") for the analogous idea in a [Lorentzian manifold](https://en.wikipedia.org/wiki/Pseudo-Riemannian_manifold#Lorentzian_manifold "Pseudo-Riemannian manifold")). 
Although this definition uses the reflexive convention we could have chosen the irreflexive convention in which the order relation is [irreflexive](https://en.wikipedia.org/wiki/Irreflexive_relation "Irreflexive relation") and [asymmetric](https://en.wikipedia.org/wiki/Asymmetric_relation "Asymmetric relation"). 
The [causal relation](https://en.wikipedia.org/wiki/Causal_relation "Causal relation") of a [Lorentzian manifold](https://en.wikipedia.org/wiki/Lorentzian_manifold "Lorentzian manifold") (without closed [causal curves](https://en.wikipedia.org/wiki/Causal_curve "Causal curve")) satisfies the first three conditions. It is the local finiteness condition that introduces spacetime discreteness. 
## Comparison to the continuum
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=3 "Edit section: Comparison to the continuum")]
Given a causal set we may ask whether it can be [embedded](https://en.wikipedia.org/wiki/Embedding "Embedding") into a [Lorentzian manifold](https://en.wikipedia.org/wiki/Lorentzian_manifold "Lorentzian manifold"). An embedding would be a map taking elements of the causal set into points in the manifold such that the order relation of the causal set matches the causal ordering of the manifold. A further criterion is needed however before the embedding is suitable. If, on average, the number of causal set elements mapped into a region of the manifold is proportional to the volume of the region then the embedding is said to be _faithful_. In this case we can consider the causal set to be 'manifold-like'. 
A central conjecture of the causal set program, called the _Hauptvermutung_ ('fundamental conjecture'), is that the same causal set cannot be faithfully embedded into two spacetimes that are not similar on large scales. 
It is difficult to define this conjecture precisely because it is difficult to decide when two spacetimes are 'similar on large scales'. Modelling spacetime as a causal set would require us to restrict attention to those causal sets that are 'manifold-like'. Given a causal set this is a difficult property to determine. 
### Sprinkling
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=4 "Edit section: Sprinkling")]
[![](https://upload.wikimedia.org/wikipedia/commons/thumb/d/d5/CausalSet%281000Points%29.png/250px-CausalSet%281000Points%29.png)](https://en.wikipedia.org/wiki/File:CausalSet\(1000Points\).png)A plot of 1000 sprinkled points in 1+1 dimensions
The difficulty of determining whether a causal set can be embedded into a manifold can be approached from the other direction. We can create a causal set by sprinkling points into a Lorentzian manifold. By sprinkling points in proportion to the volume of the spacetime regions and using the causal order relations in the manifold to induce order relations between the sprinkled points, we can produce a causal set that (by construction) can be faithfully embedded into the manifold. 
To maintain Lorentz invariance this sprinkling of points must be done randomly using a [Poisson process](https://en.wikipedia.org/wiki/Poisson_process "Poisson process"). Thus the probability of sprinkling  n {\displaystyle n} ![{\\displaystyle n}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a601995d55609f2d9f5e233e36fbe9ea26011b3b) points into a region of volume  V {\displaystyle V} ![{\\displaystyle V}](https://wikimedia.org/api/rest_v1/media/math/render/svg/af0f6064540e84211d0ffe4dac72098adfa52845) is 
P ( n ) = ( ρ V ) n e − ρ V n ! {\displaystyle P(n)={\frac {(\rho V)^{n}e^{-\rho V}}{n!}}} ![{\\displaystyle P\(n\)={\\frac {\(\\rho V\)^{n}e^{-\\rho V}}{n!}}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/6e4dc7c3314c2e68b9b61e7b56179b93472978ba)
where  ρ {\displaystyle \rho } ![{\\displaystyle \\rho }](https://wikimedia.org/api/rest_v1/media/math/render/svg/1f7d439671d1289b6a816e6af7a304be40608d64) is the density of the sprinkling. 
Sprinkling points as a regular lattice would not keep the number of points proportional to the region volume. 
## Geometry
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=5 "Edit section: Geometry")]
Some geometrical constructions in manifolds carry over to causal sets. When defining these we must remember to rely only on the causal set itself, not on any background spacetime into which it might be embedded. For an overview of these constructions, see.[[7]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Brightwell-7)
### Geodesics
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=6 "Edit section: Geodesics")]
[![](https://upload.wikimedia.org/wikipedia/commons/thumb/1/1a/CausalSet180Geodesic.png/250px-CausalSet180Geodesic.png)](https://en.wikipedia.org/wiki/File:CausalSet180Geodesic.png)A plot of geodesics between two points in a 180-point causal set made by sprinkling into 1+1 dimensions
A _link_ in a causal set is a pair of elements  x , y ∈ C {\displaystyle x,y\in C} ![{\\displaystyle x,y\\in C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a27aed230492081fc1937d9c96f9fc3cccd9f40a) such that  x ≺ y {\displaystyle x\prec y} ![{\\displaystyle x\\prec y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/61de07b95a935ac198f35c2b0eb8aa0babdb2fb1) but with no  z ∈ C {\displaystyle z\in C} ![{\\displaystyle z\\in C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/d7aacf822637d597d4c57b877c40319c33b4628f) such that  x ≺ z ≺ y {\displaystyle x\prec z\prec y} ![{\\displaystyle x\\prec z\\prec y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c13f68a739a2fdb4a24a24741202e570c1caccf1). 
A _chain_ is a sequence of elements  x 0 , x 1 , … , x n {\displaystyle x_{0},x_{1},\ldots ,x_{n}} ![{\\displaystyle x_{0},x_{1},\\ldots ,x_{n}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/07f25c501dcae43605157c6512a5ae3e30817750) such that  x i ≺ x i + 1 {\displaystyle x_{i}\prec x_{i+1}} ![{\\displaystyle x_{i}\\prec x_{i+1}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/205b2e47f5e60134963991fe02373095b6d837c7) for  i = 0 , … , n − 1 {\displaystyle i=0,\ldots ,n-1} ![{\\displaystyle i=0,\\ldots ,n-1}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a24c993042b221ec2ea57ac190a1e8f07a9c42d3). The length of a chain is  n {\displaystyle n} ![{\\displaystyle n}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a601995d55609f2d9f5e233e36fbe9ea26011b3b). If every  x i , x i + 1 {\displaystyle x_{i},x_{i+1}} ![{\\displaystyle x_{i},x_{i+1}}](https://wikimedia.org/api/rest_v1/media/math/render/svg/6d5a1c40924f8f4ac00fe999b82c791e98bb5dfa) in the chain form a link, then the chain is called a _path_. 
We can use this to define the notion of a [geodesic](https://en.wikipedia.org/wiki/Geodesic "Geodesic") between two causal set elements, provided they are order comparable, that is, causally connected (physically, this means they are time-like). A geodesic between two elements  x ⪯ y ∈ C {\displaystyle x\preceq y\in C} ![{\\displaystyle x\\preceq y\\in C}](https://wikimedia.org/api/rest_v1/media/math/render/svg/f1a3a9ae6f2066cd27003262db43034f1857431c) is a chain consisting only of links such that 
  1. x 0 = x {\displaystyle x_{0}=x} ![{\\displaystyle x_{0}=x}](https://wikimedia.org/api/rest_v1/media/math/render/svg/14745b8f7723f2031eb388152d53b1b39b43bb66) and  x n = y {\displaystyle x_{n}=y} ![{\\displaystyle x_{n}=y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e04ca9c091f77536a76c196199de9df858fc41e4)
  2. The length of the chain,  n {\displaystyle n} ![{\\displaystyle n}](https://wikimedia.org/api/rest_v1/media/math/render/svg/a601995d55609f2d9f5e233e36fbe9ea26011b3b), is maximal over all chains from  x {\displaystyle x} ![{\\displaystyle x}](https://wikimedia.org/api/rest_v1/media/math/render/svg/87f9e315fd7e2ba406057a97300593c4802b53e4) to  y {\displaystyle y} ![{\\displaystyle y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/b8a6208ec717213d4317e666f1ae872e00620a0d).


In general there can be more than one geodesic between two comparable elements. 
Myrheim[[8]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Myrhiem-8) first suggested that the length of such a geodesic should be directly proportional to the proper time along a timelike geodesic joining the two spacetime points. Tests of this conjecture have been made using causal sets generated from sprinklings into flat spacetimes. The proportionality has been shown to hold and is conjectured to hold for sprinklings in curved spacetimes too. 
### Dimension estimators
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=7 "Edit section: Dimension estimators")]
Much work has been done in estimating the manifold [dimension](https://en.wikipedia.org/wiki/Dimension "Dimension") of a causal set. This involves algorithms using the causal set aiming to give the dimension of the manifold into which it can be faithfully embedded. The algorithms developed so far are based on finding the dimension of a [Minkowski spacetime](https://en.wikipedia.org/wiki/Minkowski_spacetime "Minkowski spacetime") into which the causal set can be faithfully embedded. 
  * Myrheim–Meyer dimension


This approach relies on estimating the number of  k {\displaystyle k} ![{\\displaystyle k}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c3c9a2c7b599b37105512c5d570edc034056dd40)-length chains present in a sprinkling into  d {\displaystyle d} ![{\\displaystyle d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e85ff03cbe0c7341af6b982e47e9f90d235c66ab)-dimensional Minkowski spacetime. Counting the number of  k {\displaystyle k} ![{\\displaystyle k}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c3c9a2c7b599b37105512c5d570edc034056dd40)-length chains in the causal set then allows an estimate for  d {\displaystyle d} ![{\\displaystyle d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e85ff03cbe0c7341af6b982e47e9f90d235c66ab) to be made. 
  * Midpoint-scaling dimension


This approach relies on the relationship between the proper time between two points in Minkowski spacetime and the volume of the [spacetime interval](https://en.wikipedia.org/wiki/Spacetime#Spacetime_intervals "Spacetime") between them. By computing the maximal chain length (to estimate the proper time) between two points  x {\displaystyle x} ![{\\displaystyle x}](https://wikimedia.org/api/rest_v1/media/math/render/svg/87f9e315fd7e2ba406057a97300593c4802b53e4) and  y {\displaystyle y} ![{\\displaystyle y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/b8a6208ec717213d4317e666f1ae872e00620a0d) and counting the number of elements  z {\displaystyle z} ![{\\displaystyle z}](https://wikimedia.org/api/rest_v1/media/math/render/svg/bf368e72c009decd9b6686ee84a375632e11de98) such that  x ≺ z ≺ y {\displaystyle x\prec z\prec y} ![{\\displaystyle x\\prec z\\prec y}](https://wikimedia.org/api/rest_v1/media/math/render/svg/c13f68a739a2fdb4a24a24741202e570c1caccf1) (to estimate the volume of the spacetime interval) the dimension of the spacetime can be calculated. 
These estimators should give the correct dimension for causal sets generated by high-density sprinklings into  d {\displaystyle d} ![{\\displaystyle d}](https://wikimedia.org/api/rest_v1/media/math/render/svg/e85ff03cbe0c7341af6b982e47e9f90d235c66ab)-dimensional Minkowski spacetime. Tests in conformally-flat spacetimes[[9]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-Reid-9) have shown these two methods to be accurate. 
## Dynamics
[[edit](https://en.wikipedia.org/w/index.php?title=Causal_sets&action=edit&section=8 "Edit section: Dynamics")]
An ongoing task is to develop the correct dynamics for causal sets. These would provide a set of rules that determine which causal sets correspond to physically realistic spacetimes. The most popular approach to developing causal set dynamics is based on the [sum-over-histories](https://en.wikipedia.org/wiki/Sum-over-histories "Sum-over-histories") version of [quantum mechanics](https://en.wikipedia.org/wiki/Quantum_mechanics "Quantum mechanics"). This approach would perform a sum-over-causal sets by growing a causal set one element at a time. Elements would be added according to quantum mechanical rules and interference would ensure a large manifold-like spacetime would dominate the contributions. The best model for dynamics at the moment is a classical model in which elements are added according to probabilities. This model, due to David Rideout and [Rafael Sorkin](https://en.wikipedia.org/wiki/Rafael_Sorkin "Rafael Sorkin"), is known as classical sequential growth (CSG) dynamics.[[10]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-10) The classical sequential growth model is a way to generate causal sets by adding new elements one after another. Rules for how new elements are added are specified and, depending on the parameters in the model, different causal sets result. 
In analogy to the [path integral formulation](https://en.wikipedia.org/wiki/Path_integral_formulation "Path integral formulation") of quantum mechanics, one approach to developing a quantum dynamics for causal sets has been to apply an [action principle](https://en.wikipedia.org/wiki/Action_principle "Action principle") in the sum-over-causal sets approach. Sorkin has proposed a discrete analogue for the [d'Alembertian](https://en.wikipedia.org/wiki/D%27Alembertian "D'Alembertian"), which can in turn be used to define the [Ricci curvature scalar](https://en.wikipedia.org/wiki/Ricci_curvature_scalar "Ricci curvature scalar") and thereby the Benincasa–Dowker action on a causal set.[[11]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-11)[[12]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-12) [Monte-Carlo simulations](https://en.wikipedia.org/wiki/Monte_Carlo_method "Monte Carlo method") have provided evidence for a continuum phase in 2D using the Benincasa–Dowker action.[[13]](https://en.wikipedia.org/wiki/Causal_sets#cite_note-13)
