# Window Capture Router

AI-HUB companion integration for:

```text
D:\GitHub\window-capture-router
```

This integration is intentionally thin. It only registers the capture hotkeys
and launches the Python router from the repo venv.

## Hotkeys

```text
Ctrl+Alt+Space  copy selected text and open the routing GUI
Ctrl+Alt+E      pick a UI Automation element, copy its text, then open the GUI
Ctrl+Alt+O      select a screen region for OCR fallback, then open the GUI
Ctrl+Alt+I      inspect the active window
```

`Ctrl+Alt+R` stays with AI-HUB Research Links.
