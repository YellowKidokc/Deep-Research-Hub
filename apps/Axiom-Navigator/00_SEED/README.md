# 00_PRIMORDIAL

The invariant foundation of Theophysics.

## Structure

Each stage uses **identical internal structure**:

```
P#_STAGE/
├─ A_AXIOMS/        ← What must be true
├─ D_DEFINITIONS/   ← What terms mean
├─ E_EVIDENCE/      ← What grounds this empirically
└─ R_RELATIONS.md   ← Depends/enables/constrains
```

This repetition is intentional. It signals: **this is not ad hoc.**

## The Six Stages

| Stage | Name | Core Lock |
|-------|------|-----------|
| P0 | ORIGIN | Something exists rather than nothing |
| P1 | CONSCIOUSNESS | Observation occurs |
| P2 | INFORMATION | Reality is structured |
| P3 | COHERENCE | Stability is non-accidental |
| P4 | AGENCY | Choice is real |
| P5 | INCOMPLETENESS | No system can fully explain itself |

## Rules

1. **No metaphysics language** in axioms
2. **No scripture** in axioms
3. **No persuasion** — only structure
4. **Definitions usable by atheist, physicist, and theologian alike**
5. **Evidence from physics, math, logic, neuroscience only**
