# DOC-IIT-002: Observer Definition Without Collapse

## The Apparent Circularity

**Claim:** "Observer and measurement are mutually dependent - the observer causes collapse, but collapse defines what counts as an observer. This is circular."

## Why This Is Wrong

### Type Discipline Resolution

Observer and measurement belong to DIFFERENT ontological categories:

| Concept | Category | Definition Source |
|---------|----------|-------------------|
| Observer (Φ) | **Ontic** (what exists) | IIT axioms |
| Measurement | **Epistemic** (what we learn) | Quantum formalism |

You cannot have circularity between different categories. That's a category error.

### IIT Defines Observer INDEPENDENTLY

Integrated Information Theory (IIT 4.0) defines consciousness/observer via FIVE AXIOMS:

1. **Intrinsicality:** Experience exists for itself
2. **Composition:** Experience is structured
3. **Information:** Experience is specific
4. **Integration:** Experience is unified
5. **Exclusion:** Experience is definite

**Critical point:** NONE of these axioms mention measurement or collapse.

The observer (system with Φ > 0) is defined by:
- Intrinsic causal structure
- Irreducibility of the whole to parts
- Maximally Irreducible Conceptual Structure (MICS)

This is a TOPOLOGICAL definition, not a functional one.

### Collapse Is a Candidate Mechanism

We propose that observers with Φ > Φ_threshold can induce wavefunction collapse.

But this is a **hypothesis about what observers DO**, not a definition of what they ARE.

| Statement | Type | Circular? |
|-----------|------|-----------|
| "Observers are defined by Φ" | Definition | No |
| "Observers cause collapse" | Hypothesis | No |
| "Collapse defines observers" | NOT CLAIMED | - |

### The Directionality

```
IIT Axioms → Observer Definition (Φ)
           ↓
Observer exists independently
           ↓
Observer MAY cause collapse (empirical claim)
           ↓
Collapse is downstream effect, not definition
```

This is unidirectional. No circle.

## Formal Structure

### Observer Definition (IIT)

```
Φ = max_{partition} [ I(whole) - Σ I(parts) ]
```

Where:
- I = integrated information
- partition = any way of cutting the system
- Φ = irreducibility of the whole

**This definition requires:**
- A physical system
- Causal connections between elements
- Information integration

**This definition does NOT require:**
- Quantum mechanics
- Measurement
- Collapse
- Any epistemic process

### Collapse Hypothesis (Separate)

IF Φ > Φ_c, THEN γ (collapse rate) increases:

```
γ = γ_0 · f(Φ)
```

This is an EMPIRICAL CLAIM about observers, not part of their definition.

## Defeat Condition

This resolution fails if:
1. IIT axioms are shown to REQUIRE measurement for coherence
2. Φ cannot be defined without reference to collapse
3. Observer-independent collapse is demonstrated (making observer role undefined)

## The Deeper Point

Many critics conflate:
- What something IS (ontology)
- What something DOES (function)
- How we KNOW about it (epistemology)

IIT separates these cleanly:
- Observer IS a system with integrated information
- Observer DOES (possibly) collapse wavefunctions
- We KNOW observers through behavioral/neural correlates
