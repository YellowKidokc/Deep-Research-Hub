# DOC-META-000: Circularity vs Feedback

## The Core Confusion

Critics repeatedly confuse two fundamentally different things:

| Concept | Type | Example | Problem? |
|---------|------|---------|----------|
| **Vicious Circularity** | Definitional | "A is B, B is A" | ❌ YES - no grounding |
| **Feedback Loop** | Dynamical | Thermostat | ✅ NO - standard dynamics |

**Theophysics contains feedback loops. It contains ZERO vicious circularities.**

---

## What Makes Circularity Vicious

### The Definitional Test

A circularity is vicious IFF:
1. Term A is DEFINED in terms of B
2. Term B is DEFINED in terms of A
3. Neither has independent grounding

Example of vicious circularity:
> "What is justice?" → "Giving people what they deserve"
> "What do they deserve?" → "What justice requires"

This is definitionally empty. No content.

### What Theophysics Does NOT Do

We never define:
- Information in terms of physical law (Information is primitive - A1.3)
- Observer in terms of measurement (Observer is IIT-defined - D5.1)
- χ in terms of Φ (χ is aggregation of Φ - scale-typed)
- Coherence in terms of fruits (Coherence causes fruits - reflective model)
- Grace in terms of system need (Grace is external input - exogenous)

Each term has INDEPENDENT grounding.

---

## What Feedback Actually Is

### Dynamical Coupling

Feedback means: A influences B, and B influences A, over TIME.

```
dA/dt = f(A, B)
dB/dt = g(A, B)
```

This is NOT circular. This is coupled differential equations.

### Examples Everywhere

| System | Feedback Loop | Circular? |
|--------|--------------|-----------|
| Thermostat | Temperature → Heater → Temperature | No |
| Predator-Prey | Rabbits → Foxes → Rabbits | No |
| Economy | Prices → Demand → Prices | No |
| Body | Blood sugar → Insulin → Blood sugar | No |
| Theophysics | χ → Fruits → χ (via behavior) | No |

All of these are DYNAMICAL systems with feedback. None are definitionally circular.

---

## The Category Error

Critics commit a **category error** when they say:

> "A affects B and B affects A, therefore circular!"

This confuses:
- **Ontological grounding** (what defines what)
- **Causal influence** (what affects what)

### Ontological Grounding
- Must be unidirectional or independent
- Creates definitional hierarchy
- Circularity here = meaninglessness

### Causal Influence
- Can be bidirectional
- Creates dynamical coupling
- Feedback here = normal physics

## How to Test for Vicious Circularity

### Step 1: Isolate Definitions
Write down the definition of each term WITHOUT reference to the other.

If you can't → vicious circularity
If you can → proceed to Step 2

### Step 2: Check Directionality
Is the relationship:
- A DEFINES B → Unidirectional (fine)
- A CAUSES B → Causal (fine, even if bidirectional)
- A = B by definition → Identity (check if both grounded)

### Step 3: Verify Independence
Can term A be measured/observed without B?
Can term B be measured/observed without A?

If both yes → no circularity
If no → check if this is measurement coupling (acceptable) or definitional coupling (unacceptable)

## The Formal Criterion

**Theophysics Circularity Test:**

For any pair (A, B) alleged to be circular:

1. Write def(A) without B
2. Write def(B) without A
3. If both succeed → NOT circular
4. If relationship exists → classify as:
   - Derivation (A → B)
   - Causation (A ↔ B dynamically)
   - Measurement coupling (A observed via B)
   - Aggregation (A = f(B_i))

**NONE of these are vicious circularity.**
