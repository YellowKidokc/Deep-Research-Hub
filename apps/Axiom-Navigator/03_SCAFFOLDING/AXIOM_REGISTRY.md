## Canonicalization Rules

### Rule 1: AX-Numbers are Primary

The AX-001 to AX-188 chain is the **canonical reference system**. All other numbering systems map TO this.

### Rule 2: Content Consolidation

When multiple files exist for same concept:

- **High-quality manual content** (A1.1, A1.2, A1.3) → Merge into AX-XXX
- **Template content** (O1.1, O1.2) → Replace with AX-XXX
- **2.0 content** (A8.1, A9.1) → Keep as canonical, link from AX-XXX

### Rule 3: Bidirectional Links

Every A-number file should link to its AX-number equivalent:

```markdown
> **Canonical Version:** [[AX-067_Binary_Sign]]
```

Every AX-number file should reference its source:

```yaml
source: A8.1-Binary-Sign.md (has 2.0 content)
```
