### 2026-10-12 — Rewrite-by-selection via the hub's own OpenRouter key (deliberate fork of the AV path)

- **Core change, deliberate fork.** `packages/openwriter/src/context-menu/ContextMenu.tsx` `callPluginAction`: actions starting with `drh:` now POST `{ slot, text, instruction?, contextBefore, contextAfter }` to the drh plugin's `/api/drh/rewrite` instead of `/api/voice/apply-editor` (the hosted, billed Author's Voice service, which does not exist in this copy — the upstream call was dead here). Everything else is reused, not duplicated: the loading blur, the selection-size guard, the [[START_SELECTION]]/[[END_SELECTION]] markers for sub-paragraph selections (the marked text is what we send; the W_rewrite prompts are told to change only what is inside), and the landing path — the plain-text reply is wrapped back into node JSON and flows through the same `stripSelectionMarkers` → prefix/suffix diff → `applyRewrite`/`applyNodeChangesFromBridge` code as AV, so rewrites land as blue pending rewrites. Errors surface via `showToast(message, 'error')` with the server's plain-language error.
- `plugins/drh/src/index.ts`: `POST /api/drh/rewrite` — validates the slot against `<hub>/prompts/W_rewrite.json` (by id or number; 400 unknown slot, empty text, custom without instruction, >6000 words), assembles system (file parts) + user (input template with `{text}`/`{instruction}`/`{contextBefore}`/`{contextAfter}`) messages, calls `https://openrouter.ai/api/v1/chat/completions` (60s timeout; 502 with the upstream message on API/network failure; the key is never logged or returned), strips quotes/preamble/code-fence wrapping from the reply, and logs like `prompts/run_slot.py`: exact request JSON to `data/api/requests/<rid>.json`, one line to `data/api/log.jsonl` (`W/<n>` slot, model, tokens in/out). New configSchema fields: `openrouterKey` (env `OPENROUTER_API_KEY`) and `model` (override; default the slot's model). Also `contextMenuItems()`: five `has-selection` items — `drh:shorter`, `drh:plainer`, `drh:as_the_skeptic`, `drh:unforgotten_sentence`, `drh:custom` (promptForInput) — labelled "Rewrite: …".
- Prompt set (hub repo): `prompts/W_rewrite.json` (slots 1–5, 6–10 null; provider openrouter, model `openai/gpt-4o-mini` (DeepSeek was first choice but is blocked by this OpenRouter account's provider allowlist), key env `OPENROUTER_API_KEY`) + `prompts/W_rewrite/` (`RETURN.md` shared output rules + one mode file per slot). Row added to `prompts/README.md`. W slots are run by the drh plugin, not `run_slot.py` (file parts become the system message, input template the user message).

Limitations (v1): the reply is plain text, so inline formatting (bold, links) inside a rewritten paragraph is not preserved — the pending rewrite shows the change and can be rejected; multi-paragraph selections come back as plain paragraphs split on blank lines (heading levels not preserved).

Checks: `npm run build` clean; route exercised through a mock-express harness with a stubbed `fetch` standing in for OpenRouter (request assembly, auth header, slot validation, quote/preamble stripping, 503 without key, 502 on upstream/network errors, request file + log.jsonl written, key never in any response). No live OpenRouter call was made from this environment.

### 2026-10-12 — Run on the doc, chat column, labelled AI edits

- **Run on the doc** (`StoryTab.tsx` + `.css`): every checklist item, extra and outline section gets a ◎ pick toggle (kept per doc in localStorage). - **Chat column** (`src/drh/ChatColumn.tsx` + `.css`, wired in `App.tsx`): a resizable column between the doc and the right rail (CHAT tab on the doc's right edge opens it; hidden in focus mode; drawer in overlay mode). - **Labelled AI edits** (`src/decorations/ai-edit-badges-plugin.ts`, registered in `PadEditor.tsx`; CSS in `decorations/styles.css`): every pending rewrite/insert/delete is outlined and gets a badge pinned above it — `API · <model> · <Story run | Chat>` (why-line as tooltip; unlabelled agent writes show "AI edit", dashed) — with **⇠ Original / Show AI ⇢** (swaps the paragraph in place via the Review tab's preview state), ✓ accept and ✕ reject.
- `src/drh/ai-edits.ts`: shared plumbing — doc → `[pN]` paragraphs with light markdown (bold/italic/code/links survive a rewrite and are parsed back), selection scope, `requestRevise`, `landEdits` (keeps block type and heading level; a blank line splits into pending inserts; empty text proposes a delete), the label store (localStorage), reveal/flash, and the original/accept/reject helpers.
- `plugins/drh/src/index.ts`: `POST /api/drh/revise` `{ mode: run|chat, paragraphs, goals?, instruction?, editable?, history?, topic? }` → `{ reply, edits: [{ id, text, why }], model }`. Runs `prompts/W_revise.json` (slot 1 `run_goals`, slot 2 `chat`) with `response_format: json_object`, 180s timeout, 30,000-word cap; edits outside `editable`, unknown ids, duplicates and no-op edits are dropped. - Prompt set (hub repo): `prompts/W_revise.json` + `prompts/W_revise/` (`RULES.md` JSON contract and editing rules, `run_goals.md`, `chat.md`). Row in `prompts/README.md`.
